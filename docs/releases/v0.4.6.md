# LearnChain v0.4.6

This patch release focuses on deep-dive reliability and LearnChain export stability. It adds a configurable timeout for long-running deep-dive requests and fixes production LearnChain uploads by targeting the canonical `www.learnchain.co` host directly.

## Changed

- Added a configurable deep-dive timeout to the AI configuration flow and persisted it in saved app config.
- Threaded the configured deep-dive timeout through the LLM backend so provider requests use the selected limit.
- Updated config summaries to show the saved deep-dive timeout alongside provider details.

## Fixed

- Fixed LearnChain document exports failing against production because `learnchain.co` returned a `307 Temporary Redirect` to `www.learnchain.co`.
