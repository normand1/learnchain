# LearnChain v0.4.0

This release expands LearnChain beyond the TUI with new headless CLI workflows, adds first-time LearnChain account setup and document export support, and broadens Claude integration across deep-dive generation and bundled skills. It also tightens the npm release pipeline so published packages track release tags correctly.

## Highlights

- Added headless CLI commands for config management, deep-dive generation, bundled skill installation, and Codex action template printing.
- Added first-time LearnChain setup with persisted authentication and LearnChain document export support.
- Added bundled Claude Code skill support, Claude deep-dive generation, and stronger Claude Code CLI integration.
- Improved deep-dive and repository export flows with richer research bundles and configurable sections.
- Hardened the npm publish workflow with release-tag version alignment and OTP-aware publishing.

## Added

- CLI commands to update config values, generate Codex or Claude deep dives, install bundled skills, and print the Codex action template.
- First-time LearnChain account setup flow in the TUI.
- Persisted LearnChain authentication for export workflows.
- LearnChain-backed document export support alongside existing repository flows.
- Bundled Claude Code deep-dive skill support.

## Changed

- Expanded deep-dive generation with richer research bundling and better document export plumbing.
- Reworked menu and configuration flows to better surface onboarding, setup, and publish-ready workflows.
- Refreshed the README, bundled skills, and install assets to reflect the new CLI and setup experience.

## Fixed

- Fixed npm publish handling so package versions align with release tags.
- Added OTP-aware publish support to reduce npm release failures.
