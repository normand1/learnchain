# LearnChain v0.4.5

This patch release makes configuration behave like a real global app install. LearnChain now stores its settings in a user-global config location by default, while still reading older repo-local configs so existing setups migrate forward without losing their saved provider selection.

## Changed

- Moved LearnChain's primary config file to a user-global `app_config.toml` path instead of the current working directory.
- Added legacy fallback and best-effort migration from `config/app_config.toml` so prior local setups still load.
- Updated CLI config commands to print the actual config file path they modify.
- Refined the npm install message so global installs show `learnchain` commands and local installs show `npx learnchain`.

## Fixed

- Fixed npm-installed LearnChain sessions launched from different terminals or directories unexpectedly reverting to default provider settings.
