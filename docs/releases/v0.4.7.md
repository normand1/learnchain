# LearnChain v0.4.7

This patch release simplifies LearnChain's maintainer release process. It replaces the old chained GitHub Actions publish flow with one release workflow, adds a local release prep script, adds a repo-only maintainer release skill, and fixes exported LearnChain document links so they open in the dashboard instead of the raw API endpoint.

## Added

- Added `scripts/prepare_release.sh` to bump release versions and scaffold changelog plus release-note templates.
- Added a repo-local maintainer skill at `.codex/skills/learnchain-release/` for repeatable LearnChain release work.

## Changed

- Replaced the old `Build Binaries` plus `Publish to npm` handoff with a single `Release` workflow.
- Removed Windows from the release-critical build and test path, keeping release verification on Linux and macOS.
- Documented the maintainer release process in `docs/releasing.md` and linked it from the README.

## Fixed

- Fixed LearnChain export links so successful document exports return the dashboard document URL instead of the API route.
